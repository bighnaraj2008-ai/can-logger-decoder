## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report security issues privately via:
- GitHub Private Vulnerability Reporting on this repository.
- Direct email to security maintainers.

### Report Information

Include as much of the following as possible:
1. Type of issue (e.g., buffer overflow, out-of-bounds read, integer wrap).
2. Location of affected code with line numbers.
3. Steps or CAN frame payload to reproduce.
4. Proof-of-concept exploit or sanitizers output (ASan/Valgrind).

### Response Timelines

- **Initial Acknowledgement**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Disclosure**: Coordinated disclosure within 30 days.

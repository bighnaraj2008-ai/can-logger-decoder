# Contributing to can-logger-decoder

Thank you for contributing to `can-logger-decoder`!

## Code Standards
- Code must adhere to C99/GNU99.
- Code style is enforced via `.clang-format`: run `./scripts/check_formatting.sh`.
- Static analysis must pass cleanly: run `./scripts/run_linter.sh`.
- All unit tests and benchmarks must pass before submitting pull requests.

See `docs/CONTRIBUTORS_GUIDE.md` for complete details.
